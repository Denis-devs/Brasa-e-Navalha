# Brasa e Navalha

Site institucional fictício de uma barbearia premium.

O projeto foi desenvolvido com foco em design responsivo,
acessibilidade, organização de código e boas práticas de
desenvolvimento front-end.

## Funcionalidades

- Página inicial responsiva
- Apresentação de serviços
- Seção institucional
- Diferenciais da barbearia
- Formulário de agendamento
- Menu responsivo
- Feedback de formulário
- Navegação por seções

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Acessibilidade

O projeto utiliza práticas como:

- HTML semântico
- labels associados a campos
- atributos ARIA
- navegação por teclado
- foco visível
- skip link
- hierarquia de títulos
